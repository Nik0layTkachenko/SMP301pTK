# Контрольні питання (Лабораторна 2)

1. **Що таке class та object?** Клас — це шаблон, що описує структуру та поведінку, а об'єкт — це конкретний екземпляр цього класу в пам'яті.
2. **Що таке state та behavior?** Стан — це набір даних об'єкта. Поведінка — це методи, які об'єкт може виконувати над своїм станом.
3. **Що таке encapsulation?** Приховування внутрішнього стану об'єкта та надання доступу до нього лише через публічні методи.
4. **Що саме у вашому проєкті демонструє encapsulation?** Колекція `_tickets` у `Screening` є `private`, ззовні доступна як `IReadOnlyCollection<Ticket>`. Зміна можлива тільки через `ReserveSeat` та `CancelReservation`.
5. **Що таке abstraction?** Виділення ключових характеристик і приховування деталей реалізації, створення "контракту" (наприклад, `ITicketPricingStrategy`).
6. **Навіщо потрібен interface?** Для визначення контракту, який мають реалізувати класи, не прив'язуючись до їхнього базового класу.
7. **Що таке polymorphism?** Здатність об'єктів з однаковим інтерфейсом по-різному реагувати на виклики (різні реалізації контракту).
8. **Покажіть polymorphism у власному коді.** `ITicketPricingStrategy pricing = new StudentPricingStrategy();` та `pricing.CalculatePrice(...)`.
9. **Що таке inheritance?** Механізм, за яким похідний клас успадковує властивості та методи базового класу.
10. **Що таке composition?** Побудова об'єктів шляхом включення інших як полів ("HAS-A"). `Screening` HAS-A `Movie` та `Hall`.
11. **Чим private відрізняється від protected?** `private` доступний лише в класі, `protected` — в класі та його спадкоємцях.
12. **Чому public List<T> { get; set; } часто є поганим рішенням для domain model?** Дозволяє змінювати список напряму ззовні, порушуючи бізнес-правила об'єкта.
13. **Коли interface доцільніший за abstract class?** Коли потрібен лише контракт без базової реалізації, або коли потрібне множинне успадкування інтерфейсів.
14. **Наведіть приклад порушення стану object, якого ваша модель не дозволяє.** Неможливо продати квиток на вже зайняте місце або повернути його після початку сеансу.
