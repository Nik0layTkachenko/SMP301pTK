# Контрольні питання

1. **Що таке Git?**
   Розподілена система контролю версій для збереження історії змін проєкту.
2. **Чим Git відрізняється від GitHub або GitLab?**
   Git — це локальний інструмент, а GitHub/GitLab — вебсервіси для віддаленого хостингу репозиторіїв.
3. **Що таке repository?**
   Сховище проєкту та історії його змін.
4. **Що таке commit?**
   Зафіксований стан змін.
5. **Що таке branch?**
   Окрема лінія розробки (рухомий покажчик на commit).
6. **Для чого використовується HEAD?**
   Покажчик на поточну активну гілку або останній commit.
7. **Що виконує merge?**
   Об'єднання змін з однієї гілки в іншу.
8. **Для чого потрібен Pull Request?**
   Запит на злиття змін з можливістю їхнього попереднього перегляду.
9. **Чим .NET project відрізняється від solution?**
   Project — це одна програма або бібліотека, а solution об'єднує кілька project-ів для спільної роботи.
10. **Для чого використовується .csproj?**
    Файл конфігурації проєкту, який містить інформацію про залежності, версію фреймворку та налаштування збірки.
11. **Що таке project reference?**
    Посилання одного проєкту на інший у межах solution, що дозволяє використовувати його код.
12. **Навіщо код предметної області винесено до окремого Domain project?**
    Для розділення відповідальності: бізнес-логіка (Domain) відокремлюється від точки входу/інтерфейсу (App), що полегшує тестування і підтримку.
